# Luvo 프로토타입 — 약물 이력과 투약 체크

수정일: 2026-11-07

## 1. 핵심 경험

**처방전 이력으로 현재 약 목록을 만들고, 보호자는 복용 여부 토글과 시간대별 투약 체크만 한다. 병원에 다녀오면 문서 사진만 올린다. 이 과정이 그대로 건강 기록이 된다.**

## 2. 사용자 흐름

### 처음 사용

서비스 접속 → 강아지 이름 입력 → 지금까지의 처방전·진단서 사진 업로드 → 처방 이력에서 현재 약과 오늘 투약 일정 자동 구성.

로그인과 회원가입은 없다. 등록할 약이 없으면 문서 기록부터 시작한다.

### 약별 복용 여부 토글

- 처방 이력에서 구성한 약마다 **복용 중 ON / 복용 안 함 OFF** 토글을 둔다.
- OFF로 바꾸면 그 시점부터 복용하지 않은 기간을 기록하고 해당 약의 투약 체크를 잠시 숨긴다.
- 다시 ON으로 바꾸면 미복용 기간을 닫고 처방에 따른 투약 체크를 다시 표시한다.
- 별도의 시작·중단·재시작 등록 화면이나 새 처방 입력을 요구하지 않는다. 잘못 누른 시각이나 기간은 수정할 수 있다.

토글은 실제 복용 여부와 미복용 기간을 기록한다. 처방 내용·용량·기간은 처방전 이력을 기준으로 유지한다. ON으로 바꾸어도 종료된 처방 기간을 연장하지 않는다.

### 매일 투약 체크

오늘 화면 → 시간대별 약 목록 → 먹인 약 체크 → 자동 저장.

체크는 예정된 투약 회차에 연결하고 체크한 시각도 남긴다. 미체크는 해당 회차의 미확인 상태이고, 토글 OFF는 명시적으로 복용하지 않은 기간이다. 날짜를 바꾸어 과거 기록을 보거나 체크를 수정할 수 있다.

### 병원 방문 후

처방전·진단서 사진 업로드 → AI가 기존 병력·처방과 비교 → 문서에 명확한 변경 사항 자동 반영 → 변경 내용과 예상 변화 안내.

- 처방 날짜·기간·변경 내용을 시간순으로 반영하여 현재 유효한 약 목록과 용량·투약 일정을 갱신한다.
- 약명·용량·시간·적용 날짜 등이 불명확하거나 기존 기록과 충돌할 때만 보호자에게 확인한다.
- 새 문서에 약이 빠졌다는 이유만으로 기존 약을 자동 중단하지 않는다.
- 보호자가 남긴 미복용 기간은 처방 이력과 별도로 유지하며, 문서 업로드로 OFF 상태를 자동 해제하지 않는다.
- 반영된 내용은 바로 보여주며 수정·되돌리기가 가능하다. 같은 문서를 다시 올려도 이력이 중복되지 않게 한다.

안내는 **이번에 바뀐 내용 / 처방에 따른 예상 변화 / 주의·확인할 사항**으로 짧게 구성한다. 예상 변화는 문서·수의사 설명과 검증된 정보에 근거하며, 실제 발생한 변화처럼 표현하지 않는다. 근거가 없으면 확인이 필요하다고 표시한다.

### 기록 보기

시간순으로 진단·처방 원본과 변경 이력, 토글로 기록한 미복용 기간, 회차별 투약 체크를 함께 본다. 문서가 작성된 날짜와 업로드한 날짜는 구별한다.

## 3. 최소 화면

## 4. 프로토타입 저장·AI 구성

- 로그인 없이 **브라우저 내부 저장소(IndexedDB)**에 강아지 정보, 원본 사진, 처방 이력, 토글 상태·미복용 기간, 회차별 투약 체크를 저장한다.
- 여기서 브라우저 저장은 새로고침 후에도 유지하는 방식으로 정의한다. 같은 브라우저에서 이어서 쓰며, 다른 기기와 동기화하지 않는다.
- 브라우저 데이터 삭제 시 기록도 사라진다. 프로토타입에는 전체 기록 초기화 기능을 둔다.
- AI 분석이 필요할 때만 Hono API를 통해 **Cloudflare AI Gateway**로 호출하고 결과를 브라우저에 저장한다. API 키는 서버에서 관리한다.
- 프로토타입의 건강 기록은 서버 D1·R2에 보관하지 않는다. AI 분석 요청에 전달하는 자료와 서버·Gateway 로그의 보존 범위는 별도로 제한한다.
- 첫 범위는 **문서 업로드 → 처방 자동 반영 → 시간대별 투약 체크 → 기록 조회**다. 이미지 변화 감지와 매일 건강 상태 입력은 포함하지 않는다.
