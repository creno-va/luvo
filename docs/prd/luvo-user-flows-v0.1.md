# Luvo 프로토타입 — 문서로 시작하는 강아지 건강 기억

수정일: 2026-11-07

## 1. 처음 시작

**진단서·처방전 촬영/업로드 → OCR → 정보 필드 자동 입력 → 사용자 확인·저장 → 짧은 건강 브리핑.**

- 로그인·강아지 정보 직접 입력으로 시작하지 않는다.
- 문서에서 강아지 이름, 품종, 성별, 문서상 연령, 진단·의심 소견·과거 병력, 약과 투약 일정을 읽는다.
- 문서에 없는 정보는 만들어내지 않는다. 빈 양식·잘린 표를 구분하고 인식된 값을 필드에 채운 뒤 항상 사용자 확인을 거쳐 저장한다. 동물과 보호자 정보, 진단·발급·발병일, 1회 용량과 판매 수량을 구분한다.
- 처음 등록된 현재 처방약은 토글 ON으로 시작한다. 지난 처방 기간을 임의로 연장하지 않는다.

## 2. 이후의 반복 흐름

### 매일

선택한 강아지의 오늘 약 확인 → 먹인 뒤 해당 시간대 체크 → 실제 투약 이력 저장 → 브리핑 갱신.

- 빈 체크는 미확인이다. 미복용 또는 정상 상태로 해석하지 않는다.
- 약별 토글 OFF는 그 시점부터 미복용 기간을 기록한다. ON으로 돌리면 기간을 닫는다.
- 처방 내용과 실제 복용 여부는 분리한다. 새 문서를 올려도 기존 OFF 상태를 임의로 해제하지 않는다.

### 병원에 다녀오면

즉시 진단서·처방전 촬영 → 기존 기록과 비교 → 기본 정보·병력·약 업데이트 → 이전 병력까지 연결한 브리핑.

- 읽은 값을 미리 채워 확인받은 뒤 반영한다. 과거 문서를 늦게 올려도 최신 정보를 덮어쓰지 않는다.
- 진단/의심/과거력/호전·종료 기록을 구별하여 원본과 함께 시간순으로 남긴다.
- 문서·통합 타임라인·브리핑은 업로드 시각이 아닌 서류의 진료 날짜·시간을 기준으로 구성한다. 시간이 없으면 날짜만 기록하고 시간 미기재로 표시하며, 날짜가 불명확하면 확인받는다.
- 새 처방전에서 누락된 약을 자동 중단하지 않는다. 중복 문서는 다시 적용하지 않는다.

### 다른 강아지의 문서라면

문서의 환자 정보 확인 → 기존 강아지에 연결 또는 새 강아지 등록 → 해당 강아지로 전환.

- 이름만 같거나 품종·성별·생년월일이 충돌하면 연결할 강아지를 확인한다.
- 상단 선택기에서 강아지를 바꾸며 관리한다.
- 각 강아지의 약, 문서, 병력, 투약 체크, 브리핑은 섞이지 않는다.

## 3. AI 건강 브리핑

AI 역할은 OCR에 그치지 않고, 한 강아지의 누적 진단·처방·실제 투약 기록을 함께 분석하는 것이다.

| 내용 | 사용자에게 보여줄 것 |
| --- | --- |
| 짧은 요약 | 현재 기록으로 확인되는 상태를 2~3문장으로 |
| 현재 상태 | 함께 고려할 병력·처방과 근거 진료 기록 |
| 앞으로 확인할 변화 | 기록과 수의학 참고 지침이 뒷받침하는 조건부 가능성 |
| 준비할 일 | 관찰해 둘 내용, 기록 준비, 기존 재검 계획 확인·병원 상담 질문 |
| 알 수 없는 점 | 부족한 검사·관찰 정보와 해석의 한계 |

- 실제 발생한 변화와 미래 가능성을 구별한다. 없는 질환을 확진하거나 발생 확률·치료 성공을 만들어내지 않는다.
- 브리핑에서 문서 원본과 참고 지침을 확인할 수 있다. 약 용량·중단·재시작을 지시하지 않는다.
- 새 기록 후, 다음 날 앱 재접속 시 또는 직접 다시 분석할 때 갱신한다. 같은 내용의 분석은 재사용한다.
- 브라우저 저장 프로토타입이므로 앱을 닫은 동안에는 분석하지 않는다.

## 4. 화면과 저장

- 최초: 문서 촬영·업로드 화면.
- 등록 후: 한 화면에 브리핑 → 예상 변화·대응 → 현재 약 토글·시간별 체크 → 최근 타임라인.
- 상단 날짜는 캘린더 바텀시트로, 강아지 이름은 별도 강아지 목록 화면으로 이동한다. 전체 타임라인에서는 병력 기록 범위·처방 변경별 기간·복용 쉼 기간을 확인한다.
- 하단 고정 업로드 버튼에서 처방전·진단서 사진을 각각 넣고 함께 정리한다. 별도 동의 체크박스 없이 분석 안내를 표시한다.
- 형광 초록색 primary, 중요 정보·날짜는 Paperlogy, 본문은 Pretendard를 사용한다. 데스크톱은 브리핑과 투약·최근 기록을 두 열로 배치한다.
- 기록과 사진은 브라우저 IndexedDB에 저장한다. 기존 기록은 유실 없이 이전한다.
- 분석에 동의한 문서와 해당 강아지의 건강 기록만 Hono API → Cloudflare AI Gateway로 전달한다. 서버에 건강 기록을 저장하지 않는다.
