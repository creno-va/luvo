# 약 정보 조회

약 리스트의 각 검색 버튼 → 별도 약 정보 페이지 → 자동 웹 검색 → 한국어 요약과 출처 확인. 이름·성분명은 페이지에서 수정해 다시 검색할 수 있으며 브라우저 뒤로 가기로 원래 기록에 돌아간다. 기존 처방·투약 기록을 수정하지 않는다.

## 실행 경로

- `POST /api/medications/research`: `{ name, ingredient?, productName? }`만 받는다. 환자 정보, 투약량, 병력은 전달하지 않는다.
- Workers AI Scout가 검색어를 최대 2개 구성한다. `AI.websearch`의 Ceramic 검색을 `default` AI Gateway로 호출한다.
- 실제 검색에 반환된 수의학 참고 문헌·규제기관·제조사 도메인의 자료를 사용한다. 검색 설명이 없는 결과는 제외한다. 상위 3개 원문은 7초·512KB 제한으로 읽고, 접근이 막히면 발췌문으로 요약한다. 모든 리다이렉트에도 같은 HTTPS/도메인 검증을 적용한다.
- AI가 약의 정체·일반 용도·관찰할 반응·주의점·수의사에게 물어볼 내용을 한국어로 작성한다. 각 설명의 출처 ID와 실제 근거 문구를 대조한다. 존재하지 않는 인용, 다른 동물종의 근거, 숫자 투약량·처방 변경 지시는 제외한다.
- 모호한 약명이나 근거 부족은 미확인으로 표시한다. 임의의 대체 약이나 AI 상식만으로 임상 설명을 채우지 않는다.

## UI 및 운영

- 모바일 단일 열, 기존 형광 초록·Paperlogy·Pretendard·Lucide 디자인 유지.
- 로딩, 빈 결과, 이름 확인 필요, 오류·재시도, 출처별 원문/발췌 표시, 검색어 확인 지원.
- 검색 결과는 현재 브라우저 탭 메모리에 최대 40개·1시간 재사용한다. 새로 확인 버튼은 웹을 다시 검색한다. IndexedDB·D1에는 조회 결과를 저장하지 않는다.
- 서버 응답은 `no-store`. IP별 분당 4회 제한. AI 추론은 Gateway 캐시·로그 수집을 끈다. 검색어는 AI Gateway와 검색 공급자에 전달되며, 검색 요청의 로그·청구에는 Gateway 설정이 적용된다.
- Web Search API는 계정의 AI Gateway 크레딧 또는 저장된 공급자 키가 필요하다. 별도 브라우저 키는 사용하지 않는다. 검색 공급자가 실패하면 모델 기억으로 대체하지 않고 재시도를 안내한다.
